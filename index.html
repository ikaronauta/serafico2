Ejercicio 1 CSS - Serafico San Antonio de Padua

  1. Crear un nuevo proyecto llamado ejercicio_css_3_julian_ortiz (El nombre de cada uno).
  2. Abrir el nuevo proyecto con Visual Studio Code en el PC, o TrebEdit desde el celular.
  3. Crear el index.html.
  4. Crear la estructura básica de una página web.
  5. Crear el título de la página web, con la etiqueta que corresponde. (El título puede ser cualquiera).
  6. Crear un Subtítulo de la página web con la respectiva etiqueta para ese fin.
  7. Crear una etiqueta div con el id contenedor.
  8. Dentro de la etiqueta div se va a insertar una imagen (Cualquier imagen). Se le debe colocar la clase claseimagenPrincipal y se deben aplicar estilos a esta imagen con CSS usando el selector de clase.
  9. Se deben crear dos etiquetas p dentro de la etiqueta div, y se le deben aplicar estilos con ayuda de los selectores combinados.
  10. Crear un footer donde se debe colocar el nombre de la persona que desarrolló la actividad.
  11. Crear la etiqueta style para aplicar los estilos CSS.
